# Bxel v0.1.0

The first release of Bxel, a pixel art editor with a fixed palette. Every pixel points at a swatch,
so a drawing never gains a colour you did not choose.

## New

- Draw sprites with the Pencil, Eraser, Fill, Picker, Shapes, Select and Move tools. Mirror X and
  Mirror Y paint both sides, and one stroke is one undo step.
- Paint patterns that repeat. With Tiled preview on, a stroke that leaves one edge continues from
  the opposite edge.
- Work with a palette that has a colour limit. Change a swatch and every pixel that uses it follows.
- Animate with frames, layers, tags, durations and onion skin.
- Cut sheets into sprites, lay sprites out on a sheet and paint on several sprites at once.
- Build tilesets and tilemaps, and import a Tiled map.
- Import PNG, GIF and APNG images with a colour mapping step that shows the original beside the
  reduced picture. Animated files arrive as frames with their durations.
- Export Sprite PNG, frames, GIF or APNG animation, sprite sheets and JSON or tilemap data, at whole
  number scales from 1 to 8.
- Keep work in a project folder where each asset is its own file, or pack it into one file.
- Let an assistant program edit through the same commands as the screen. It is off until you turn
  it on, and Bxel asks before it connects.
- Open the demo project from the Help menu to look around first.

## Platforms

- Windows gets an installer that links the Bxel file types to the app.
